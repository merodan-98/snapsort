=======================================================
[기말과제] 스냅소트(SnapSort) 이미지 분류 프로그램 실행 설명서
=======================================================

본 프로젝트는 머신러닝/딥러닝 프레임워크를 일절 사용하지 않고,
NumPy와 파이썬 기본 기능만을 활용하여 K-Nearest Neighbors(KNN) 알고리즘과 
색상 히스토그램 기반 특징 추출기를 직접 구현한 인공지능 응용프로그램입니다.

[1] 프로그램 실행 순서 (기말과제 기준 스크립트)
-------------------------------------------------------
본 프로그램은 학습 -> 테스트 -> 성능 평가 순으로 실행해야 정상 동작합니다.

1. 학습 스크립트 실행 (train.py)
   - 터미널(혹은 명령 프롬프트)에서 아래 명령어를 실행합니다.
     > python train.py
   - 기능: dataset_augmented 폴더 내의 이미지에서 특징을 추출하고 학습/평가용 데이터로 분할합니다.
   - 산출물: knn_model.pkl (학습 완료된 모델 파일), test_dataset.pkl (평가용 데이터), train_log.txt (학습 로그)

2. 1회 테스트 스크립트 실행 (test_1_time.py)
   - 사용자가 직접 테스트해볼 수 있는 스크립트입니다.
   - 터미널에서 아래 명령어를 실행합니다.
     > python test_1_time.py
   - 실행 후 텍스트 프롬프트에 이미지 파일의 절대경로(또는 상대경로)를 입력하고 엔터를 누르면 카테고리를 예측하여 출력합니다.
     (예: dataset_augmented\game\game_1.jpg)

3. 성능 평가 스크립트 실행 (3_evaluate.py)
   - 모델의 전반적인 정확도(Accuracy)를 평가하는 스크립트입니다.
   - 터미널에서 아래 명령어를 실행합니다.
     > python 3_evaluate.py
   - 기능: train.py에서 저장해 둔 test_dataset.pkl 과 knn_model.pkl을 불러와 모델의 예측률을 검증합니다.
   - 산출물: test_log.txt (성능 평가 결과 로그)

[2] 발표 시연용 추가 앱 실행 방법 (보너스 프로그램)
-------------------------------------------------------
위의 과제 제출용 기본 스크립트 외에, 직접 시연할 때 사용하기 좋은 GUI 및 웹 앱이 포함되어 있습니다.

A. GUI 앱 실행 (파이썬 기본 내장 tkinter 사용)
   > python 4_gui_app.py
   - '이미지 1장 분류': 한 장씩 업로드해 카테고리만 확인합니다.
   - '갤러리 일괄 정리': 폴더 또는 여러 파일을 선택하면 KNN으로 분류한 뒤
     지정한 저장 폴더 아래 game / person / finance 하위 폴더로
     복사(원본 유지) 또는 이동(원본 삭제)합니다. 발표 시연용 핵심 기능입니다.

B. 웹(Web) 앱 실행 (Flask 기반 웹 서버)
   > python app.py
   - 실행 후 웹 브라우저를 열고 http://127.0.0.1:5000 에 접속하여 시연할 수 있습니다.
   
C. 원클릭 데모 실행
   - 폴더에 있는 `실행_데모시작.bat` 파일을 더블클릭하면 관련 스크립트를 편리하게 실행해줍니다. (웹 데모 실행됨)

=======================================================
* 본 프로그램의 알고리즘 핵심 구현은 `2_knn_classifier.py` 파일에 모두 포함되어 있습니다.
